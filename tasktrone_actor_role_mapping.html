Abstract roles are the platform's internal role model. Domain roles are the project_member_role and task_assignment_role enum values that the tenant configures. Only two rows are domain-exclusive; all others are structurally shared.
Use case segmentation by layer
Use case cluster Belongs to Scope Domain
UC-1 — Project lifecycle Platform core Create, configure, phase-advance, close a project both
UC-2 — Task operations Platform core Create, assign, update, complete tasks and subtasks both
UC-3 — Board management Platform core Configure columns, WIP limits, swimlanes; move cards both
UC-4 — Dependency graph Platform core Define predecessor/successor links with lag time both
UC-5 — File & requirements Platform core Attach versioned files to tasks; fulfill requirements both
UC-6 — Quality checks Platform core Create check, record measurements, pass/fail, trigger rework both
UC-7 — Metrics & analytics Platform core Record cycle/lead time, defects, equipment utilization both
UC-8 — Equipment registry Domain-specific Track machines: status, maintenance schedule, usage per task Mfg only
UC-9 — Permit & compliance docs Domain-specific Attach permit drawings; record inspection milestones by AHJ MEP only
UC-10 — Phase vocabulary Domain mapping Configure enum labels per tenant (phase names, role titles) both
UC-1 through UC-7 are fully reusable — build them once. UC-8 and UC-9 are additive domain modules that extend the core without replacing it. UC-10 is the configuration layer that lets both verticals share a single schema.
